# vocwm

> **Vertically Oriented Cyclic Window Manager**

A Wayland compositor built on **wlroots** and configured via **Lua**, built around a single idea: workspaces live in **2D space**, not a flat list.

- Spatial grid navigation (up/down/left/right)
- Snake / cyclic traversal
- Bounded and infinite workspace generation
- Fully scriptable with Lua
